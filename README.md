### 👤 About Me

I am a Software Developer with a technical background in computer systems and networking. I work across both frontend and backend development, building console, desktop, web, and mobile applications.  

I work with Java, Spring Boot, Angular, JavaScript, TypeScript, Kotlin, HTML, and CSS. I also have experience working with databases such as MariaDB and MySQL.  

My technical background includes Linux, system administration, networking, virtualization, and AWS. I also use tools such as Maven, Git, GitHub, and Docker for project management, version control, build automation, and deployment.  

My goal is to continue growing in software engineering, contributing to projects across different areas of development while applying my knowledge of both software and the systems that support it.
